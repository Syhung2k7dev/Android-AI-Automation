# Android AI Automation

An Android accessibility-based automation app with local-first interaction, visual recognition, scheduled tasks, and optional AI-assisted recovery.

## Project principles

- Android 13+ compatibility, with explicit permission and service-state checks.
- Accessibility-based gestures for user-authorized automation.
- Local-first execution; cloud AI is optional and used only for bounded recovery suggestions.
- Human-readable, versioned automation profiles with validation before execution.
- Foreground service notification and transparent pause/stop controls.
- No root requirement.
- No anti-cheat evasion, detection bypass, or automation against protected systems.

## Initial target

Oppo Reno6 Z 5G running Android 13 / ColorOS.

## Development status

Project initialized. Android application scaffold and CI build pipeline are the next milestones.
